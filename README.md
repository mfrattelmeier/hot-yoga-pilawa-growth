# Hot Yoga Pilawa Growth, CRM, and Marketing System

This repository is the engineering and documentation home for Hot Yoga Pilawa's growth, CRM, and marketing system across HubSpot, Meta/Facebook, and Fitssey.

## Phase 1

Phase 1 is a read-only audit of HubSpot, Meta, and Fitssey. Its purpose is to document the current systems, data, integrations, and open decisions before any external system is modified or any synchronization and marketing automation are built.

No API access or write operations are part of the initial repository setup.

## Repository Areas

- `docs/` — business, lifecycle, data, architecture, attribution, and strategy documentation
- `audits/` — read-only audit outputs grouped by source system
- `integrations/` — future integration code grouped by source system
- `analytics/` — funnel, attribution, retention, and revenue analysis
- `marketing/` — audiences, lifecycle, campaigns, and content planning
- `scripts/` — operational and development scripts
- `tests/` — automated tests
- `config/` — non-secret configuration
